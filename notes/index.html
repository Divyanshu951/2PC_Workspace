Positioning in CSS:

Relative positioning

Relative CSS positioning is a layout technique that allows you to adjust an element's position relative to where it would normally appear in the document flow. Here's a concise explanation of how it works:


  • Normal flow: By default, elements are positioned according to the normal document flow.
  • Relative positioning: When you set position: relative; on an element, it remains in the normal flow, but you can now use offset properties to move it.
  • Offset properties: You can use top, bottom, left, and right to shift the element from its original position.
  • Original space: The element's original space is preserved in the layout, even if it's moved.
  • Z-index: Relative positioning allows you to use the z-index property to control stacking order.
